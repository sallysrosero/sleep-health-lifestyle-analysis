# Sleep Health and Lifestyle Analysis

This repository contains the final project for analyzing factors influencing sleep health and lifestyle choices.

## Project Overview
The goal of this project is to explore how lifestyle factors such as physical activity, stress level, and age relate to sleep outcomes including sleep duration, sleep quality, and sleep disorders.

## Methods Used
- Exploratory Data Analysis (mean, median, standard deviation)
- Data visualization (histograms, boxplots, scatter plots, heatmap)
- Hypothesis testing using Welch’s two-sample t-tests
- Correlation analysis (Pearson, Spearman, Kendall’s Tau, Point-Biserial, Phi coefficient)

## Tools
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn

## Notes
The dataset is uploaded locally when running the notebook in Google Colab and is not included in this repository.
